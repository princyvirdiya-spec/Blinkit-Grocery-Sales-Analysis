# Blinkit-Grocery-Sales-Analysis
This project analyzes grocery sales data using Python, SQL, and Excel to find useful business insights. Data cleaning, analysis, and dashboard creation were performed to understand sales trends and outlet performance.

Tools Used:

    Python (Pandas, Matplotlib)

    MySQL

    Microsoft Excel (Dashboard)

Key Work Done:

    Cleaned and standardized data

    Analyzed total sales, average sales, and ratings

    Performed SQL queries using GROUP BY and aggregate functions

    Created charts and an Excel dashboard

Outcome:

Identified top-selling products and outlet categories

Analyzed sales contribution by outlet size and location

Skills Gained:
Python | SQL | Excel Dashboard | Data Analysis
